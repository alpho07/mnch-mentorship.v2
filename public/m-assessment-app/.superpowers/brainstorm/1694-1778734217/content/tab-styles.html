Click a phone to select that style. All show the same content — only the tab strip differs.

A

Underline tabs (TikTok / YouTube)

Text labels flush with the header, white underline slides to the active tab. Maximises vertical space — no extra height added. Clean and familiar.

B

Floating pill tabs (Uber / Google Maps)

Rounded pill buttons sit below the header on the coloured band. Active tab pops out in white. Feels tactile and button-like — good for 2–4 tabs.

C

Segmented control (iOS native)

All tabs in one rounded container; active segment fills white. Very iOS-native feel. Labels get truncated if there are many tabs.
