Backend API — New Controllers

6 new controllers in app/Http/Controllers/Api/. All delegate to existing Services — no business logic duplicated. Routes added to routes/api.php under the existing Sanctum middleware group.

MentorshipController

Scoped to authenticated user — mentor_id = me OR accepted co-mentor. Uses Training model filtered to type='facility_mentorship'.
GET/api/v1/mentorships
My mentorships with class counts and overall status
GET/api/v1/mentorships/{id}
Training detail + classes + KPIs (mirrors MentorDashboard loader)
GET/api/v1/mentorships/{id}/classes
All MentorshipClass records for this training
GET/api/v1/mentorships/{id}/classes/{classId}
Class detail + modules list + participant count

ClassModuleController

Module lifecycle. Calls ClassModule::start() and ClassModule::complete() — exact same methods as Filament page actions.
GET/api/v1/classes/{classId}/modules
ClassModules with status, session count, attendance rate, programModule name
POST/api/v1/modules/{moduleId}/start
Start module → generates attendance_token, creates MenteeModuleProgress rows
ClassModule::start()
POST/api/v1/modules/{moduleId}/complete
Complete module → finalises all participant progress records
ClassModule::complete()
GET/api/v1/modules/{moduleId}/sessions
ClassSessions with scheduled dates, duration, status

AttendanceApiController

Mentor marks module attendance for their roster. Delegates entirely to AttendanceService.
GET/api/v1/modules/{moduleId}/attendance
Participant roster with present / absent / not_started status
POST/api/v1/modules/{moduleId}/attendance/{participantId}
Mark one participant. Body: { status: "present"|"absent" }
AttendanceService::markManualModuleAttendance()
POST/api/v1/modules/{moduleId}/attendance/bulk
Mark all at once. Body: { attendances: [{participant_id, status}] }
AttendanceService — loop

MenteeApiController

Mentee's own classes and progress. Mirrors MenteeClassProgressController as JSON. Self-confirm attendance without needing a token link — user is authenticated.
GET/api/v1/me/classes
All enrolled classes with training summary and completion %
GET/api/v1/me/classes/{classId}
Class detail + all MenteeModuleProgress records + confirmed attendance flags
POST/api/v1/me/classes/{classId}/modules/{moduleId}/attend
Self-confirm attendance. Guards: module in_progress, user enrolled.
AttendanceService::confirmModuleAttendance()

ParticipantController

Mentor views the mentee roster and drills into individual progress.
GET/api/v1/classes/{classId}/participants
All ClassParticipants with user info, completion %, attendance rate
GET/api/v1/participants/{participantId}/progress
Full MenteeModuleProgress breakdown — mirrors MenteeProgress Filament page

GlobalTrainingController

MOH/national trainings. Admins see all; participants see only their registered trainings.
GET/api/v1/trainings
Scoped to user's role — all for admin, my registrations for participants
GET/api/v1/trainings/{id}
Training detail with participant count, dates, location, program
GET/api/v1/trainings/{id}/participants
TrainingParticipant roster with completion_status and attendance_status
