Backend API — New Controllers & Routes

Mirrors the existing app/Http/Controllers/Api/ pattern. Leverages existing Services — no business logic duplicated.

MentorshipController

Scoped to authenticated user's mentorships (mentor_id = me OR co-mentor). Uses Training model with type='facility_mentorship'.
GET /api/v1/mentorships
List my mentorships with class counts and status
GET /api/v1/mentorships/{id}
Training detail + classes + KPIs (mirrors MentorDashboard loader)
GET /api/v1/mentorships/{id}/classes
All MentorshipClass records for this training
GET /api/v1/mentorships/{id}/classes/{classId}
Class detail + modules + participant count

ClassModuleController

Module lifecycle actions. Calls ClassModule::start() and ClassModule::complete() — same logic as Filament page actions.
GET /api/v1/mentorships/{id}/classes/{classId}/modules
All ClassModules with programModule name, status, session count, attendance rate
POST /api/v1/modules/{moduleId}/start
Start module → generates attendance_token, creates MenteeModuleProgress rows
ClassModule::start()
POST /api/v1/modules/{moduleId}/complete
Complete module → finalises MenteeModuleProgress for all participants
ClassModule::complete()
GET /api/v1/modules/{moduleId}/sessions
ClassSessions for this module with scheduled dates and status

AttendanceApiController

Mentor marks attendance for a whole module roster. Delegates to AttendanceService — no new business logic.
GET /api/v1/modules/{moduleId}/attendance
Participant roster with present/absent/not_started status for this module
POST /api/v1/modules/{moduleId}/attendance/{participantId}
Mark one participant present or absent. Body: { status: "present"|"absent" }
AttendanceService::markManualModuleAttendance()
POST /api/v1/modules/{moduleId}/attendance/bulk
Mark all participants at once. Body: { attendances: [{participant_id, status}] }
AttendanceService — loop

MenteeApiController

Mentee's own classes and progress. Mirrors MenteeClassProgressController but returns JSON. Mentee self-confirms attendance via mobile (no token link needed — already authenticated).
GET /api/v1/me/classes
All ClassParticipant records for current user with class + training summary
GET /api/v1/me/classes/{classId}
Class detail + all MenteeModuleProgress records + attendance flags
POST /api/v1/me/classes/{classId}/modules/{moduleId}/attend
Self-confirm attendance. Guards: module must be in_progress, user must be enrolled.
AttendanceService::confirmModuleAttendance()

GlobalTrainingController

MOH/national trainings. Read-mostly for field workers. Admins see all; participants see trainings they're registered for.
GET /api/v1/trainings
List trainings scoped to user's role — all for admin, my registrations for participants
GET /api/v1/trainings/{id}
Training detail with participants count, dates, location, program
GET /api/v1/trainings/{id}/participants
TrainingParticipant roster with completion_status and attendance_status

ParticipantController

Mentor views per-mentee progress across all modules in a class.
GET /api/v1/classes/{classId}/participants
All ClassParticipants with user info, overall completion %, attendance rate
GET /api/v1/participants/{participantId}/progress
Full MenteeModuleProgress breakdown for one mentee (mirrors MenteeProgress Filament page)
